3. Motion analytics (read-only)

Tuning lives on the camera. This camera ignores ONVIF writes — SetVideoAnalyticsConfiguration returns success and changes nothing (verified: sent Sensitivity=55, read back 80). Detection zones work, but ONVIF cannot read them. The camera enforces its configured zone correctly (verified: motion inside triggers, motion outside does not), yet the ActiveCells mask below stays byte-identical whatever the zone is — it was never wired to the real config. So it is shown as a raw bit pattern and must not be read as the current detection area. Sensitivity, by contrast, does track. Set zones in the camera's own web UI; shown here to explain why detection behaves as it does.
